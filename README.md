# GM Notes

> A minimalist Markdown note-taking app powered by GitHub.

🌐 **Online Site**: [https://winfirm.top/gmnotes/](https://winfirm.top/gmnotes/)

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📝 **Markdown Editor** | Write with Markdown syntax and preview rendered results in real time |
| 🔄 **GitHub Sync** | All notes are stored as `.md` files in your GitHub repository |
| ✨ **AI Writing Assistant** | Optimize, expand, compress, translate, and summarize with local AI |
| 🔍 **Quick Search** | Instantly find any note by title with the built-in search |

## 🚀 Quick Start

1. Visit [GM Notes](https://winfirm.top/gmnotes/)
2. Choose your language (English / 中文)
3. Start writing your notes!

## 📖 How It Works

- Your notes are stored as Markdown files in your GitHub repository
- Use GitHub API to sync notes across devices
- Local AI assistant helps improve your writing

## 🌍 Language Support

- 🇬🇧 [English](https://winfirm.top/gmnotes//gmnotes.html)
- 🇨🇳 [中文版](https://winfirm.top/gmnotes//gmnotes-zh.html)

## 🔧 Built With

- GitHub API for data storage and synchronization
- Markdown for note formatting
- Local AI for writing assistance
